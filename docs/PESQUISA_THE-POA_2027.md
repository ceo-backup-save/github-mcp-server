O TripWatch já está preparado:

```bash
cd tripwatch

```

Com a chave, o provedor passa a consultar:

- `google_flights` para THE → POA em 29/01/2027 (volta 01/02/2027);
- `google_hotels` para cada hotel em Porto Alegre, check-in 29/01 e check-out 01/02.

Alternativa: conectar o **LetsFG** (`https://letsfg.co/mcp`) como MCP no Arena/Claude e usar
`search_flights`/`search_hotels` em tempo real. O TripWatch pode continuar como memória,
agendador e alertas.
